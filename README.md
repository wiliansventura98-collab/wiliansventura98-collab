### Pesquisa

- **Tese:** *Movimentos Socioespaciais e Socioterritoriais Urbanos e os 17 Objetivos do Desenvolvimento Sustentável: Estudo Comparativo entre Brasil e Argentina* (PPGG, FCT/UNESP).
- **Orientação:** Prof. Dr. Eduardo Paulon Girardi (UNESP) · **Coorientação:** Profa. Dra. Fernanda Valeria Torres (UNLP).
- **Mobilidade internacional:** doutorado sanduíche (PDSE/CAPES, 2024–2025) e estágio de pesquisa no exterior (BEPE/FAPESP, 2025–2026) na Universidad Nacional de La Plata.
- **Interesses:** geografia dos movimentos sociais, ações coletivas, território e espaço urbano, cartografia temática e bancos de dados de lutas.

### Projeto em destaque

**[DATALUTA Argentina 2024](https://wiliansventura98-collab.github.io/site-acoes/)**: base interativa das ações coletivas noticiadas na Argentina em 2024, com mapas, gráficos, contexto oficial (Censo 2022, RENABAP, eleições) e dados abertos. Em português e [espanhol](https://wiliansventura98-collab.github.io/site-acoes/es/).

[![Mapa das ações coletivas por departamento na base DATALUTA Argentina 2024](https://wiliansventura98-collab.github.io/site-acoes/assets/img/galeria/dept.jpg)](https://wiliansventura98-collab.github.io/site-acoes/)

Feita com Python (pandas, GeoPandas), JavaScript (D3.js, Leaflet) e publicada automaticamente pelo GitHub Pages. Código no repositório [site-acoes](https://github.com/wiliansventura98-collab/site-acoes).
